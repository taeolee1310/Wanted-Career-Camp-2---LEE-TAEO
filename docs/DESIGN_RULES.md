# 디자인 규칙

기준 문서는 `DESIGN-apple.md`이고, 값의 원천은 `design/tokens.json`입니다. `css/style.css`의 `:root` 변수는 이 값과 같게 유지합니다.

| 항목 | 규칙 |
| --- | --- |
| 브랜드 톤 | 제품(콘텐츠)이 말하게 하고 UI는 물러난다. 장식 없음 |
| 컬러 | 흰색 · 파치먼트(#f5f5f7) · 니어블랙(#272729) 타일이 번갈아 나옴. 색 변화가 곧 섹션 구분선 |
| 포인트 | Action Blue(#0066cc) 하나만 사용. 링크·버튼·강조에만. 어두운 면에서는 #2997ff |
| 타이포 | 제목 SF Pro Display 600 + 음수 자간, 본문 17px/400/1.47. 굵기는 300·400·600만 사용(500 금지) |
| 버튼 | 블루 pill(radius 9999px, 패딩 11×22). 눌림 상태는 `scale(0.95)` |
| 카드 | 흰색 면, 1px 헤어라인(#e0e0e0), radius 18px, 패딩 24px. 그림자 없음 |
| 그림자 | 이미지(약도)에만 `rgba(0,0,0,0.22) 3px 5px 30px`. 카드·버튼·텍스트에는 쓰지 않음 |
| 그라데이션 | 사용하지 않음 |
| 네비 | 44px 블랙 글로벌 바, 12px 링크. 833px 이하에서 햄버거 |
| 간격 | 8px 기준. 섹션 상하 80px(모바일 48px) |
| 반응형 | phone ≤ 640 · tablet ≤ 833 · desktop 1023 이하에서 4열 → 2열 |
| 접근성 | 터치 영역 44px 이상, 포커스 링 2px `primary-focus`, 본문 대비 4.5:1 이상 |

## 작업 규칙
- 화면 문구를 디자인에서 새로 쓰지 않습니다. 문구는 `content/`에서 가져옵니다.
- 새 색·간격 값이 필요하면 토큰을 먼저 추가하는 PR을 엽니다.
- 약도는 실제 지도 캡처 대신 가상 약도(`design/assets/map.svg`)를 씁니다.
- hover 상태는 문서화하지 않고, 기본·눌림 상태만 정의합니다.
