# AI 네이티브 커리어 캠프 2기 홈페이지

수업용으로 만든 커리어 캠프 소개 사이트입니다. 모집 안내, 캠프 소개, 교육 일정, 오시는 길을 4개 페이지로 보여 줍니다. 신청 버튼은 실제로 접수되지 않는 가상 기능입니다.

## 페이지

| 페이지 | 경로 | 내용 |
| --- | --- | --- |
| 메인화면 | `index.html` | 영상 배경 히어로, 16주 로드맵, 혜택, 주요 날짜, 위치, 지원서 팝업 |
| 캠프소개 | `about/index.html` | 과정, 혜택, 강사·멘토, 운영 실적, 참가 자격, 신청 방법, FAQ |
| 일정표 | `dayoff/index.html` | 단계별 로드맵, 주차별 날짜, 오프라인 일정 |
| 오시는 길 | `location/index.html` | 지도, 주소 복사, 교통 안내 |

모든 페이지가 같은 상단 메뉴·푸터를 쓰고, 오른쪽 위 버튼으로 다크·라이트 모드를 바꿀 수 있습니다. 선택한 모드는 브라우저에 저장됩니다.

## 실행 방법

빌드 과정이 없는 정적 사이트입니다.

**1. 파일로 바로 열기**
`index.html`을 브라우저로 엽니다. 대부분 동작하지만, 브라우저에 따라 영상이나 저장된 테마가 제대로 동작하지 않을 수 있습니다.

**2. 로컬 서버로 열기 (권장)**

```bash
# Python이 있을 때
python -m http.server 8000

# Node.js가 있을 때
npx serve .
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 폴더 구조

```text
├─ index.html              메인화면 (본문은 js/render.js가 그림)
├─ about/ dayoff/ location/   서브 페이지 (각자 index.html, css, js)
├─ css/
│  ├─ style.css            메인화면 스타일
│  └─ chrome.css           모든 페이지 공통: 상단 메뉴·푸터·다크 모드 색
├─ js/
│  ├─ theme.js             첫 화면 깜빡임 없이 저장된 테마 적용
│  ├─ chrome.js            모든 페이지 공통: 상단 메뉴·푸터·테마 토글·모바일 메뉴
│  ├─ render.js            메인화면 본문과 지원서 팝업
│  └─ main.js              등장 효과, 지원서 팝업 동작, 영상 제어
├─ content/data.js         화면에 나오는 문구·날짜·숫자 (window.CAMP)
├─ design/
│  ├─ tokens.json          색·글꼴·간격 기준값
│  └─ assets/hero/         히어로 배경 영상
├─ docs/                   회사 정보, 디자인·개발 규칙, 변경 이력
└─ DESIGN-apple.md         디자인 기준 문서
```

## 내용을 바꾸려면

- **문구·날짜·숫자:** `content/data.js`만 고칩니다. 값의 원본은 `docs/company.md`와 `docs/careercamp.json`이고, 날짜는 일정(`schedule`)에서만 정합니다. 요일, D-day, 모집 상태는 코드가 계산합니다.
- **색·글자 크기:** `css/style.css`와 `design/tokens.json`을 같이 고칩니다. 기준은 `DESIGN-apple.md`와 `docs/DESIGN_RULES.md`입니다.
- **상단 메뉴·푸터:** `js/chrome.js`와 `css/chrome.css`를 고치면 모든 페이지에 똑같이 적용됩니다.

## 디자인 기준

- Apple 디자인 가이드(`DESIGN-apple.md`)를 따릅니다. 밝은 면과 어두운 면이 번갈아 나오고, 포인트 색은 파란색 하나입니다.
- 글자는 13px 이상, 일반 글자 대비는 4.5:1 이상을 지킵니다. 자세한 기준은 `docs/DESIGN_RULES.md`에 있습니다.
- 화면은 640px, 833px, 1023px에서 단계적으로 바뀝니다.

## 작업 방법

- `main`에서 새 브랜치를 만들어 작업한 뒤 머지합니다. 오래된 브랜치를 그대로 머지하면 다른 사람이 만든 파일이 지워질 수 있으니, 작업 전에 `git pull origin main`으로 최신 상태를 받습니다.
- 페이지별 담당이 나뉘어 있습니다. 다른 사람 담당 파일을 고칠 때는 미리 알려 주세요.

## 알아 둘 점

- 이 사이트는 수업용 가상 페이지입니다. 지원서에 입력한 내용은 어디로도 전송·저장되지 않습니다.
- `design/assets/hero/hero-bg.mp4`가 약 28MB입니다. 저장소와 첫 로딩이 무거우니 가능하면 압축한 영상으로 바꾸는 것을 권합니다.
- 오시는 길의 구글 지도는 인터넷 연결이 있어야 보입니다.
