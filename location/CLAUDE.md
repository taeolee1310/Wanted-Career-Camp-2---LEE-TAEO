# 오시는 길 파트 (location/)

수업용 가상 커리어 캠프 홈페이지 중 "오시는 길" 페이지. 담당 파트만 수정한다.
사실과 규칙의 원본은 `1020_회사소개_작성지침_v2.md`, 디자인 원본은 `DESIGN-apple.md`.

## 범위
- 수정 가능: `location/` 안의 파일만
- 수정 금지: 지침 문서, `DESIGN-apple.md`, 다른 팀원 파트, 푸터 (푸터는 다른 담당, 보류 중)

## 기술 스택
- HTML, CSS, JavaScript만 사용. 프레임워크, 빌드 도구, 외부 라이브러리 없음
- 지도는 Google Maps "지도 퍼가기" iframe만 사용. API 키와 Maps JavaScript API는 쓰지 않음

## 구조
```text
location/
├─ index.html        # /location 페이지
├─ css/location.css  # 디자인 토큰(:root)과 스타일 전부
└─ js/location.js    # 메뉴 토글, 주소 복사
```

## 디자인 규칙 (DESIGN-apple.md 요약)
> 디자인은 나중에 바뀔 수 있다. 값은 `location.css`의 `:root` 변수에만 두어 한 곳만 고치면 되게 하고, 변경 지시가 있으면 아래 목록보다 그 지시를 따른다.
- 강조색은 `#0066cc` 하나만 쓴다. 어두운 배경 위 링크만 `#2997ff`
- 색과 크기는 `location.css`의 `:root` 변수만 쓰고 hex를 직접 쓰지 않는다
- 본문 17px/400, 제목 600. 굵기 500은 쓰지 않는다
- 버튼은 알약 모양이고 누르면 `scale(0.95)`. 카드 라운드는 18px
- 그림자와 그라데이션을 쓰지 않는다
- 섹션은 밝음, 파치먼트, 어두움 타일을 번갈아 배치한다
- 반응형 기준: 1068px, 833px(햄버거 메뉴), 640px(1열)
- 터치 영역 44px 이상, 포커스 링 유지, 시맨틱 태그와 iframe `title` 필수

## 내용 규칙
- 장소: 원티드랩 (실제 위치). 지도 iframe은 공식 퍼가기 코드
- 날짜와 일정은 이 페이지에 쓰지 않고 `../schedule.html`을 링크한다
- 문의처는 푸터에만 둔다
- 지하철, 버스, 주차 문구는 사실 확인 전 초안이다. 출구 번호와 버스 노선은 비워 둔다

## 메뉴 링크
`../index.html`, `../about.html`, `../schedule.html`, `index.html`. 팀원 파일명이 정해지면 맞춘다.

## 확인 방법
- `location/`에서 `python -m http.server` 실행 후 `http://localhost:8000` 접속. `file://`로는 열지 않는다
- 1280, 800, 375px에서 화면과 콘솔 오류를 확인한다
